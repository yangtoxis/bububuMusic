# 🔥 Хайповый музон

Discord-бот с единой музыкальной библиотекой. Никаких плейлистов и станций —
просто одна прокачанная коллекция треков, которая играет случайным образом,
не повторяясь, с полноценным DJ-управлением и голосованиями для всех
остальных.

Библиотека наполняется как душе угодно: название, ссылка на YouTube, Spotify
или Яндекс Музыку, или разом TXT-файлом на сотни треков. Сам бот находит
трек, чистит его от клипового мусора (скетчи, интро, самопромо — режется по
SponsorBlock) и кладёт в библиотеку под настоящим именем из источника.

## Что внутри

**🎵 Библиотека**
- `/add <название или ссылка>` — добавляет трек. Понимает свободный текст,
  ссылки на YouTube / Spotify / Яндекс Музыку — сам определяет, что ему дали.
- Правый клик на сообщении с `.txt` → **Apps → Импортировать треки из TXT** —
  массовая загрузка списком (`Исполнитель — Название` на строку), фоново,
  не блокируя бота. По итогу — подробный отчёт: сколько добавлено, сколько
  уже было, что не удалось и почему.
- Дубликаты не скачиваются повторно. Названия и исполнители берутся из
  реальных метаданных источника, а не из того, что вы напечатали в поиске.
- Немузыкальные куски клипа (интро-скетчи, аутро, реклама) вырезаются
  автоматически через SponsorBlock, если для видео есть разметка.

**🔀 Плеер**
- Честный шаффл: не повторяет только что сыгранный трек, старается не
  повторять исполнителя подряд, помнит последние сыгранные треки даже между
  `/stop` → `/play`.
- Материализованная очередь на 5 треков вперёд — `/queue`, с кнопкой
  перемешать.
- Кнопки прямо под объявлением трека: ⏮️ / ⏹️ / ⏸️▶️ / ⏭️, громкость 🔉🔊,
  и ссылки на поиск трека на YouTube / Spotify / Яндекс Музыке с настоящими
  логотипами площадок.
- `/pause`, `/skip`, `/remove` (удалить играющий трек из библиотеки, с
  отменой одной кнопкой), `/add-queue` (поставить трек следующим без
  сохранения в библиотеку).

**🎧 DJ и голосования**
- `/djrole add|remove|list` — любая роль (хоть несколько) даёт права DJ.
  Без настроенных ролей управлять может только «Управление сервером».
- DJ может всё: `/play`, `/stop`, `/skip`, `/pause`, `/volume`, кнопки на
  панели.
- Если DJ в канале нет — обычные пользователи запускают `/vote-start` или
  `/vote-stop`. Порог голосования — процент от числа людей в канале,
  настраивается через `/vote-settings`. Голосование живьём пересчитывается
  при входе/выходе людей из канала и сгорает по таймеру. Если в канал зашёл
  DJ во время голосования за включение — голосование отменяется, обход
  прав через толпу невозможен.

**🌍 Мультисервер**
Каждый сервер — своя независимая сессия: громкость, очередь, голосования,
подключение. Библиотека треков общая для всех серверов.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/add <track>` | DJ | Добавить трек по названию/ссылке |
| *ПКМ на сообщении → Импортировать треки из TXT* | DJ | Массовый импорт из файла |
| `/add-queue <track>` | DJ | Поставить трек следующим, без сохранения в библиотеку |
| `/library-status` | все | Статистика библиотеки |
| `/play` | DJ | Подключиться и запустить «Хайповый музон» |
| `/stop` | DJ | Остановить и отключиться |
| `/pause` | DJ | Пауза / снять с паузы |
| `/skip` | DJ | Следующий трек |
| `/remove` | DJ | Удалить играющий трек из библиотеки (с отменой) |
| `/queue` | все | Следующие 5 треков, DJ может перемешать |
| `/volume <0-100>` | DJ | Громкость, сохраняется на сервере |
| `/djrole add\|remove\|list` | Manage Server | Настройка ролей DJ |
| `/vote-settings` | Manage Server | Пороги голосований (%) |
| `/vote-start` / `/vote-stop` | все в канале | Голосование, когда DJ нет |

## Стек

Node.js 20+ · discord.js 14 · @discordjs/voice · better-sqlite3 · yt-dlp +
ffmpeg для скачивания и декодирования аудио.

## Запуск локально

```bash
npm install
cp .env.example .env   # заполнить DISCORD_TOKEN, CLIENT_ID, GUILD_ID
npm run deploy-commands
npm run dev
```

Нужны системные `ffmpeg` и `yt-dlp` в PATH.

## Деплой

Продовый вариант — Docker на VPS, `network_mode: host` (голосовому трафику
нужен прямой UDP), ffmpeg и yt-dlp ставятся в образ через apt/pip.

```bash
git clone https://github.com/yangtoxis/bububuMusic.git
cd bububuMusic
cp .env.example .env   # заполнить секреты, GUILD_ID оставить пустым в проде
docker compose up -d --build
docker compose exec bot node src/deploy-commands.js   # один раз, ~1ч на применение
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DISCORD_TOKEN`, `CLIENT_ID` | credentials бота | — |
| `GUILD_ID` | dev-сервер для мгновенных команд, пусто в проде | — |
| `DB_PATH` | путь к SQLite | `./data/bot.sqlite` |
| `LIBRARY_DIR` | куда качаются треки | `./data/library` |
| `DEFAULT_VOLUME` | громкость по умолчанию | `70` |
| `DEFAULT_VOTE_START_PERCENT` / `DEFAULT_VOTE_STOP_PERCENT` | пороги голосований | `50` |
| `VOTE_TIMEOUT_SECONDS` | сколько живёт голосование | `60` |
| `IMPORT_TRACK_TIMEOUT_SECONDS` | таймаут на трек при импорте | `90` |
| `LOG_LEVEL` | `info` / `debug` | `info` |

## Ограничения V1

Без DRM-обхода — весь звук идёт через штатное скачивание yt-dlp с YouTube.
Ссылки на Spotify и Яндекс Музыку используются только для чтения открытых
метаданных (артист/название со страницы), сам файл всегда берётся с
YouTube. Нет персональных плейлистов, поиска треков пользователем помимо
`/add`, нескольких станций и жанровых фильтров — вся суть в одной честной
библиотеке на сервер.
